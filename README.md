# سامانه جامع منابع انسانی کارکنان (HRM24 Employee Panel)

این پروژه یک پنل مدرن و واکنش‌گرا (Responsive) برای مدیریت امور پرسنلی کارکنان است که با استفاده از فریم‌ورک **Angular 19** و طراحی **Tailwind CSS** پیاده‌سازی شده است. تمرکز اصلی این پروژه بر روی **تجربه کاربری ساده (UX)** برای تمامی سطوح سواد و پشتیبانی کامل از **حالت تاریک (Dark Mode)** است.

## 🚀 ویژگی‌های کلیدی

- **طراحی فراگیر (Inclusive Design):** رابط کاربری ساده با دکمه‌های بزرگ و متون واضح برای استفاده آسان توسط همه کارکنان.
- **حالت تاریک/روشن:** قابلیت تغییر تم به صورت خودکار یا دستی با ذخیره‌سازی در حافظه مرورگر.
- **مدیریت تردد:** ثبت ورود و خروج هوشمند با نمایش وضعیت لحظه‌ای و کارکرد روزانه.
- **مدیریت مرخصی:** مشاهده مانده مرخصی و ثبت درخواست‌های جدید با فرم‌های ساده.
- **فیش حقوقی:** مشاهده خلاصه درآمد و کسورات و دانلود فایل PDF فیش‌های ماهانه.
- **پشتیبانی و تیکت:** سیستم ثبت تیکت داخلی با اعلان‌های موفقیت (Toast Notifications).
- **داشبورد هوشمند:** نمایش یادآورهای مهم، اطلاعیه‌های داخلی و رویدادهای تقویمی.
- **صفحه خوش‌آمدگویی:** لندینگ پیج زیبا با انتقال خودکار به داشبورد.

## 🛠️ تکنولوژی‌های استفاده شده

- **Framework:** Angular 19 (Standalone Components)
- **Styling:** Tailwind CSS
- **Icons:** Custom SVG Registry (بدون وابستگی به کتابخانه‌های سنگین)
- **PDF Generation:** jsPDF
- **Font:** Vazirmatn (فونت استاندارد فارسی)

## 📦 نصب و راه‌اندازی

برای اجرای پروژه در محیط توسعه، مراحل زیر را دنبال کنید:

1.  **کلون کردن مخزن:**

    ```bash
    git clone <repository-url>
    cd Hrm24Employee
    ```

2.  **نصب وابستگی‌ها:**

    ```bash
    npm install
    ```

3.  **اجرای سرور توسعه:**
    ```bash
    ng serve
    ```
    سپس مرورگر خود را باز کرده و به آدرس `http://localhost:4200/` بروید.

## 🏗️ ساختار بیلد نهایی

برای دریافت نسخه بهینه‌شده جهت انتشار روی سرور:

```bash
ng build --configuration production
```

## قابلیت‌های پیشنهادی آینده

- پس از تکمیل پروژه، امکان یک فرایند اختیاری برای تسویه اختلاف میان مبلغ بازمحاسبه‌شده رسیدهای داخلی توزیع سند و مبلغی که در زمان عملیات دریافت شده است، از طریق تعدیلات کیف پول بررسی شود. این قابلیت صرفاً پیشنهاد است و برای پیاده‌سازی تأیید نشده است.
- قرارداد تخفیف اسناد، شامل دامنه اعمال و ترتیب تخفیف‌ها، تا فاز مدیریت تخفیف باز می‌ماند.
- Expand user reports with additional reports and better-defined KPIs after reviewing business goals and available data.

## پیش‌نمایش گزارشات کاربران Fish24

- مسیر `/fish24/internal/reports/users` فقط برای مدیر سامانه و کارشناس فروش است؛ نقش پشتیبانی نه ورودی منو دارد و نه مجوز مسیر مستقیم.
- ثبت‌نام کارفرما و کارمند از زمان ثبت هویت کاربر محاسبه می‌شود. فردی که هم‌زمان نقش کارفرما و کارمند دارد در هر جمعیت مربوط یک‌بار و عضویت‌های بعدی شرکت به‌عنوان ثبت‌نام فرد جدید شمرده نمی‌شود. اعداد غیرفعال، وضعیت فعلی حساب شخص‌اند و رویداد غیرفعال‌سازی نیستند.
- تعداد و حجم بارگذاری از زمان واقعی بارگذاری فایل اصلی و اندازه واقعی بایت استفاده می‌کند؛ وضعیت پرداخت یا توزیع دخیل نیست و صفحات، گیرندگان یا نسخه‌های توزیعی فایل جدید محسوب نمی‌شوند. Fixtureهای تاریخی فعلی این دو واقعیت را نگه نمی‌دارند و بدون حدس‌زدن از آمار بارگذاری حذف و در خود صفحه اعلام می‌شوند.
- پوشش تاریخی فقط از توزیع‌های تکمیل‌شده می‌آید. دریافت تاریخی با انقضا/غیرفعال‌سازی حذف نمی‌شود؛ دسترسی فعال علاوه بر توزیع تکمیل‌شده، فعال‌بودن دسترسی و منقضی‌نشدن سند را لازم دارد. جمع کارکنان دارای سند فعال و بدون سند فعال برابر با جمعیت فعلی افراد یکتای کارمند است.
- دوره‌ها در منطقه زمانی `Asia/Tehran` و تقویم جلالی‌اند؛ هفته از شنبه آغاز می‌شود. دوره جاری از ابتدای روز/هفته/ماه/سال تا امروز و دوره قبل، کل دوره تقویمی قبلی است. «کل» فقط مجموع تا امروز را نشان می‌دهد. هر چهار انتخاب دوره مستقل و به تفکیک کاربر در مرورگر نگهداری می‌شوند.
- نمودارها با Highcharts و بسته رسمی Angular ساخته شده‌اند. ماژول accessibility برای نام/توضیح نمودار، پیمایش صفحه‌کلید و فناوری‌های کمکی فعال است. Highcharts برای استفاده تجاری/داخلی شرایط مجوز تجاری دارد؛ این مخزن وجود یا خرید چنین مجوزی را ادعا نمی‌کند و مالک محصول باید پیش از انتشار شرایط مجوز را تأیید کند.
- این داشبورد نسخه اول و فقط پیش‌نمایش حافظه‌ای است؛ تاریخچه تولید، داده حذف‌شده یا ماندگاری Backend را ادعا نمی‌کند.

## پیش‌نمایش مدیریت سؤالات متداول Fish24

- مسیر داخلی `/fish24/internal/faqs` برای مدیر سامانه، کارشناس فروش و کارشناس پشتیبانی در دسترس است و زیرمنوی «تنظیمات سایت» قرار دارد.
- داده‌ها Fixture نمایشی و فقط در حافظه هستند؛ ایجاد، ویرایش، تغییر وضعیت و حذف پس از بازخوانی مرورگر بازنشانی می‌شوند و هنوز به API یا صفحه عمومی متصل نیستند.
- پاسخ‌ها متن ساده‌اند؛ شکست خط و متن‌های شبیه HTML یا فرمول بدون اجرا حفظ می‌شوند.
- خروجی ساده Excel برای مدیر سامانه و کارشناس فروش مجاز است و نقش پشتیبانی در سطح رابط و سرویس اجازه خروجی ندارد.

## پیش‌نمایش مناطق جغرافیایی Fish24

- سه مسیر داخلی مدیریت استان، شهرستان و شهر فقط برای مدیر سامانه و کارشناس فروش فعال‌اند. نقش پشتیبانی همچنان می‌تواند از انتخاب‌گرهای جغرافیایی مجاز در فرم‌های دیگر استفاده کند، اما به مدیریت یا خروجی دسترسی ندارد.
- رابطه والد پس از ساخت تغییرپذیر نیست. هر رکورد وضعیت مستقل خود را حفظ می‌کند، ولی دسترس‌پذیری برای انتخاب جدید علاوه بر وضعیت خودش به فعال‌بودن تمام والدها وابسته است.
- غیرفعال‌کردن والد، وضعیت ذخیره‌شده فرزندان و انتخاب‌های موجود پروفایل را تغییر نمی‌دهد. مقدار موجود غیرفعال در فرم حفظ و مشخص می‌شود، اما برای انتساب جدید ارائه نمی‌شود.
- پوشش داده فعلی محدود به داده موجود پروژه است: زنجیره تهران/تهران/تهران و البرز/کرج/کرج. شناسه‌های پایدار این پیش‌نمایش برای یکپارچه‌کردن همان گزینه‌های قبلی تعریف شده‌اند؛ بانک جامع کشوری به این فاز افزوده نشده است.
- داده‌ها و تغییرات جغرافیایی فقط در حافظه‌اند و با بازخوانی کامل برنامه به Fixture اولیه بازمی‌گردند؛ فیلترها و انتخاب ستون‌ها جداگانه و برای هر کاربر/فهرست در مرورگر نگهداری می‌شوند.
