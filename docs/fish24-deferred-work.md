# Fish24 deferred work

## Internal formal invoice exports

The following specialized exports are intentionally deferred until authoritative sample files and field contracts are supplied:

- خروجی سند حسابداری
- خروجی تفصیلی مشتریان
- خروجی فاکتور

Phase 1D.7 implements only the standard plain invoice-list Excel export. The three specialized actions remain visible in the invoice-list toolbar, clearly marked as not yet implemented. Each action explains that its format awaits an authoritative reference sample and does not create or download a substitute file.
